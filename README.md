# Pius Angmortey — Personal Website

This is Version 1 of the personal portfolio website.

## Files
- `index.html` — page structure/content
- `style.css` — visual design and responsive layout
- `script.js` — mobile navigation and current year

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
2. Replace or add project links as projects become available.
3. Add certificates and a CV link when ready.
4. Review all personal information before publishing.

## Run locally
Open `index.html` in a browser.

For a better development workflow, use VS Code with a local server extension.
